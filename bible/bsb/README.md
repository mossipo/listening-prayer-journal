# Berean Standard Bible (BSB)

The Holy Bible, Berean Standard Bible, BSB, was dedicated to the public domain on April 30, 2023 (https://berean.bible/terms.htm, CC0). Converted for Akouō from the BSB USFM text (github.com/dharmatech/bsb-usfm). Footnotes and cross-reference ranges are left out; the verse text is unchanged.

Each `CODE.json` is `{ "b": book name, "c": [chapters] }`. A chapter is a list of tokens: `["h", heading]`, `["d", psalm title]`, `["p", "m"|"q1"|"q2"|...]` paragraph or poetry line, `["b"]` stanza break, `[n, text]` verse n begins, `[0, text]` the verse continues.
